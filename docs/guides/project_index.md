# Manage projects


:::info
To configure projects, use the [`projects`](/api/configs/projects_config/) property of To Do List.

To define what project a task belongs to, pass the project ID to the `project` parameter of the related [`task`](/api/configs/tasks_config/) object.

To make a certain project active on initialization, use the [`activeProject`](/api/configs/activeproject_config/) property.
:::
