# closeMenu()

### 描述 {#description}

@short: 关闭任务/项目已打开的菜单

### 用法 {#usage}

~~~js
closeMenu({
    id?: string | number
}): void;
~~~

### 参数 {#parameters}

- `id` - （可选）需要关闭菜单的任务/项目的 ID。若未指定，该方法将关闭当前已打开的菜单
