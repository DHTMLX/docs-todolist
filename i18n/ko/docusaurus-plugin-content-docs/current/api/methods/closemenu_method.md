# closeMenu()

### 설명 {#description}

@short: 태스크/프로젝트의 열린 메뉴를 닫습니다

### 사용법 {#usage}

~~~js
closeMenu({
    id?: string | number
}): void;
~~~

### 매개변수 {#parameters}

- `id` - (선택) 메뉴를 닫을 태스크/프로젝트의 ID. 지정하지 않으면 현재 열려 있는 메뉴를 닫습니다
