# Навигация с клавиатуры {#keyboard-navigation}

DHTMLX To Do List поддерживает полную навигацию с клавиатуры. Создавайте задачи, управляйте ими и организуйте их без мыши.

Горячие клавиши работают только тогда, когда задача находится в фокусе. Чтобы сфокусироваться на задаче, кликните по ней или используйте <kbd>ArrowUp</kbd> / <kbd>ArrowDown</kbd> для перемещения по списку.

:::tip
Горячие клавиши **не работают**, когда в фокусе находится поле поиска в Toolbar.
:::

:::info
Навигация с клавиатуры не работает в режиме [`readonly`](api/configs/readonly_config.md).
:::

## Обычный режим {#default-mode}

Следующие горячие клавиши работают, когда встроенный редактор **закрыт**.

### Навигация и выделение {#navigation-and-selection}

| Горячая клавиша | Описание |
| :---------------- | :---------- |
| <kbd>ArrowUp</kbd> | Перемещает выделение на предыдущую задачу |
| <kbd>ArrowDown</kbd> | Перемещает выделение на следующую задачу |
| <kbd>ArrowRight</kbd> | Разворачивает свёрнутую родительскую задачу |
| <kbd>ArrowLeft</kbd> | Сворачивает развёрнутую родительскую задачу. Если задача уже свёрнута или не имеет дочерних, перемещает выделение на родительскую |
| <kbd>Shift</kbd>+<kbd>ArrowUp</kbd> | Расширяет выделение на задачу выше. Если она уже выделена — снимает выделение |
| <kbd>Shift</kbd>+<kbd>ArrowDown</kbd> | Расширяет выделение на задачу ниже (включая её дочерние). Если она уже выделена — снимает выделение |
| <kbd>Ctrl(Cmd)</kbd>+<kbd>Click</kbd> / <kbd>Ctrl(Cmd)</kbd>+<kbd>Shift</kbd>+<kbd>Click</kbd> | Выделяет или снимает выделение с нескольких задач вместе с их дочерними:<br/>• если у задачи есть выделенные родители — снимает выделение с задачи и её родителей<br/>• если у задачи есть выделенные дочерние — снимает выделение только с самой задачи |
| <kbd>Shift</kbd>+<kbd>Click</kbd> | Выделяет диапазон задач между текущей выделенной задачей и кликнутой |

:::info
Подробнее о работе с несколькими выделенными задачами см. в руководстве [Мультивыбор](guides/multiselection.md).
:::

### Управление задачами {#task-management}

| Горячая клавиша | Описание |
| :---------------- | :---------- |
| <kbd>Enter</kbd> | Создаёт новую задачу на том же уровне, что и выделенная, перемещает на неё выделение и открывает редактор |
| <kbd>Ctrl(Cmd)</kbd>+<kbd>Enter</kbd> | Открывает встроенный редактор для выделенной задачи |
| <kbd>Space</kbd> | Отмечает выделенную задачу как выполненную. Если уже выполнена — отмечает как невыполненную |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Удаляет выделенную задачу. После удаления выделение перемещается вниз на следующую задачу или вверх на родительскую, если следующей нет |
| <kbd>Tab</kbd> | Понижает задачу — перемещает её на один уровень вложенности глубже |
| <kbd>Shift</kbd>+<kbd>Tab</kbd> | Повышает задачу — перемещает её на один уровень вложенности выше |
| <kbd>Ctrl</kbd>+<kbd>ArrowUp</kbd> | Перемещает выделенную задачу вверх в пределах того же уровня |
| <kbd>Ctrl</kbd>+<kbd>ArrowDown</kbd> | Перемещает выделенную задачу вниз в пределах того же уровня |
| <kbd>Ctrl(Cmd)</kbd>+<kbd>D</kbd> | Дублирует выделенную задачу на том же уровне |
| <kbd>Ctrl(Cmd)</kbd>+<kbd>C</kbd> | Копирует выделенную задачу (включая все дочерние) в буфер обмена |
| <kbd>Ctrl(Cmd)</kbd>+<kbd>V</kbd> | Вставляет скопированную задачу на том же уровне, что и текущая выделенная, сохраняя исходную структуру |
| <kbd>Ctrl(Cmd)</kbd>+<kbd>Z</kbd> | Отменяет последнее действие (undo) |
| <kbd>Ctrl(Cmd)</kbd>+<kbd>Y</kbd> / <kbd>Ctrl(Cmd)</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Повторяет отменённое действие (redo) |
| <kbd>Alt</kbd>+<kbd>1</kbd> / <kbd>Alt</kbd>+<kbd>2</kbd> / <kbd>Alt</kbd>+<kbd>3</kbd> | Устанавливает приоритет выделенной задачи (соответствует горячей клавише соответствующего элемента [`priorities`](api/configs/priorities_config.md)) |
| <kbd>Alt</kbd>+<kbd>0</kbd> | Сбрасывает приоритет выделенной задачи |
| <kbd>Escape</kbd> | Закрывает контекстное меню, если оно открыто. При повторном нажатии закрывает редактор, сбрасывает активную фильтрацию и сворачивает результаты поиска в Toolbar |

## Режим редактирования {#editing-mode}

Следующие горячие клавиши работают, когда встроенный редактор **открыт**.

| Горячая клавиша | Описание |
| :---------------- | :---------- |
| <kbd>Enter</kbd> | Сохраняет изменения и закрывает редактор |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Вставляет новый абзац внутри редактора |
| <kbd>Escape</kbd> | Закрывает редактор без сохранения изменений |
