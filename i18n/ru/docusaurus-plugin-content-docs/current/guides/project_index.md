# Управление проектами

:::info
Для настройки проектов используйте свойство [`projects`](api/configs/projects_config.md) компонента To Do List.

Чтобы назначить задачу проекту, передайте идентификатор проекта в параметр `project` соответствующего объекта [`task`](api/configs/tasks_config.md).

Чтобы задать активный проект при инициализации, используйте свойство [`activeProject`](api/configs/activeproject_config.md).
:::
