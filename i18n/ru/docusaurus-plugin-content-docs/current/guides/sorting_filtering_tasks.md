# Сортировка и фильтрация задач

## Сортировка задач {#sorting-tasks}

После инициализации задачи можно отсортировать одним из двух способов:

- через опцию **Sort by** меню [панели инструментов](/#toolbar) - сортировка по *тексту*, *сроку выполнения*, *дате завершения*, *дате создания* или *дате редактирования*
- через метод [`setSort()`](api/methods/setsort_method.md) - задайте пользовательскую функцию сортировки или сортируйте по [атрибуту задачи](api/configs/tasks_config.md#parameters)

Пример ниже сортирует задачи по идентификатору в порядке возрастания:

~~~js
list.setSort({
    by: task => task.id, // или by: "text"
    dir: "asc",
    // tree: true // включить древовидную сортировку, по умолчанию false
});
~~~

## Фильтрация задач {#filter-tasks}

Задачи можно отфильтровать одним из двух способов:

- через [строку поиска](/#toolbar) панели инструментов
- через метод [`setFilter()`](api/methods/setfilter_method.md) - поддерживает *строгий* режим для точного совпадения

Фрагмент ниже фильтрует задачи по определённому хэштегу в строгом режиме:

~~~js
// фильтрация данных по заданным правилам
list.setFilter({
    match: "#tag1",
    highlight: true,
    strict: true
});
~~~

Чтобы сбросить фильтрацию, передайте `match: null`:

~~~js
// сброс фильтрации
list.setFilter({ match: null });
~~~
