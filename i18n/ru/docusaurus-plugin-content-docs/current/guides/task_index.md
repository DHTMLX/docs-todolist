# Управление задачами

:::info
Для настройки задач используйте свойство [`tasks`](api/configs/tasks_config.md) компонента To Do List.
:::

Эти руководства охватывают API To Do List для работы с задачами: получение объектов задач, навигация по иерархии задач, выполнение операций CRUD и управление несколькими выделенными задачами.
