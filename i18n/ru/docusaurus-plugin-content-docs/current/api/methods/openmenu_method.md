# openMenu()

### Описание {#description}

@short: Открывает меню задачи/проекта в указанных координатах

### Использование {#usage}

~~~js
openMenu({
    id: string | number,
    type?: "task" | "user" | "project",
    coords: { x: number, y: number }
}): void;
~~~

### Параметры {#parameters}

- `id` - (обязательный) идентификатор задачи/проекта
- `type` - (необязательный) тип меню. Доступны три типа меню:
  - `task` (по умолчанию) — меню задачи
  - `user` — меню пользователя
  - `project` — меню проекта
- `coords` - (обязательный) объект с координатами x и y меню:
    - `x` - (обязательный) значение координаты x
    - `y` - (обязательный) значение координаты y
