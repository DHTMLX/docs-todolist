# closeMenu()

### Описание {#description}

@short: Закрывает открытое меню задачи/проекта

### Использование {#usage}

~~~js
closeMenu({
    id?: string | number
}): void;
~~~

### Параметры {#parameters}

- `id` - (необязательный) ID задачи/проекта, меню которого нужно закрыть. Если не указан, метод закроет текущее открытое меню
