# keypress-on-todo

## Описание {#description}

@short: Срабатывает, когда задача находится в фокусе во время использования клавиатурной навигации

## Использование {#usage}

~~~js
"keypress-on-todo": ({
    code: string,
    event: KeyboardEvent
}) => void;
~~~

### Параметры {#parameters}

Коллбэк события `keypress-on-todo` может принимать объект со следующими параметрами:

- `code` - (обязательный) код нажатой клавиши или сочетания клавиш в *нижнем регистре*. Полные списки горячих клавиш и их кодов приведены [ниже](#keyboard-shortcuts)
- `event` - (обязательный) нативный [объект события](https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent)

:::info
Для обработки внутренних событий используйте [**методы Event Bus**](category/event-bus-methods.md)
:::

### Пример {#example}

~~~js {15-17}
const { ToDo, Toolbar } = todo;
const {tasks, projects, users} = getData();

const list = new ToDo("#root", {
    tasks,
    projects,
    users
});

const toolbar = new Toolbar("#toolbar", {
    api: list.api,
});

// подписка на событие "keypress-on-todo"
list.api.on("keypress-on-todo", ({code, event}) => {
    console.log("The", code, "key is pressed"); 
});
~~~

## Горячие клавиши {#keyboard-shortcuts}

### Обычный режим {#default-mode}

Следующие сочетания клавиш работают, когда встроенный редактор **закрыт**.

| Горячая клавиша | Код клавиши | Описание                                                          |
| :-------------- | ----------- | :---------------------------------------------------------------- |
| <kbd>Escape</kbd> | `escape` | Закрывает меню, если оно открыто для задачи в момент нажатия клавиши. Повторное нажатие закроет редактор, сбросит фильтрацию и свернёт результаты поиска на панели инструментов |

:::tip
**Коды клавиш**, описанные ниже, недоступны, если фокус установлен на строке поиска панели инструментов.
:::

| Горячая клавиша | Код клавиши | Описание                                                          |
| :-------------- | ----------- | :---------------------------------------------------------------- |
| <kbd>Enter</kbd> | `enter` | Создаёт новую задачу на том же уровне, что и выбранная, перемещает выделение на созданную задачу и открывает редактор |
| <kbd>ArrowUp</kbd> | `arrowup` | Перемещает выделение вверх к предыдущей задаче |
| <kbd>ArrowDown</kbd> | `arrowdown` | Перемещает выделение вниз к следующей задаче |
| <kbd>Ctrl(Cmd)</kbd>+<kbd>Enter</kbd> | `ctrl+enter` | Открывает редактор выбранной задачи |
| <kbd>Ctrl(Cmd)</kbd>+<kbd>Click</kbd> /<br> <kbd>Ctrl(Cmd)</kbd>+<kbd>Shift</kbd>+<kbd>Click</kbd> <br> добавлено в v1.1 | `ctrl` /<br> `ctrl+shift` | Выбирает несколько задач вместе со всеми дочерними.<br> Если задача уже выбрана — снимает выделение, при этом:<br> - Если у задачи есть родители, которые тоже выбраны — снимает выделение с задачи вместе с её родителями.<br> - Если у задачи есть дочерние, которые тоже выбраны — снимает выделение только с самой задачи.|
| <kbd>Shift</kbd>+<kbd>Click</kbd> <br> добавлено в v1.1| `shift` |Выбирает диапазон задач|
| <kbd>Shift</kbd>+<kbd>ArrowUp</kbd> <br> добавлено в v1.1| `shift+arrowup` |Выбирает задачу выше текущей.<br> Если задача выше уже выбрана — снимает с неё выделение|
| <kbd>Shift</kbd>+<kbd>ArrowDown</kbd> <br> добавлено в v1.1| `shift+arrowdown` |Выбирает задачу (и все её дочерние) ниже текущей.<br> Если задача ниже уже выбрана — снимает с неё выделение|
| <kbd>Ctrl</kbd>+<kbd>ArrowUp</kbd> | `ctrl+arrowup` | Перемещает выбранную задачу вверх в пределах того же уровня |
| <kbd>Ctrl</kbd>+<kbd>ArrowDown</kbd> | `ctrl+arrowdown` | Перемещает выбранную задачу вниз в пределах того же уровня |
| <kbd>Space</kbd> | `space` | Отмечает задачу как выполненную или невыполненную в зависимости от её текущего состояния |
| <kbd>Delete</kbd> /<br><kbd>Backspace</kbd> | `delete` /<br>`backspace` | Удаляет выбранную задачу по следующей логике:<br> - после удаления дочерней задачи перемещает выделение вниз/вверх до родительской задачи <br>- после удаления родительской задачи перемещает выделение вниз к следующей родительской задаче, если она есть; иначе перемещает выделение вверх к предыдущей родительской задаче |
| <kbd>ArrowRight</kbd> | `arrowright` | Разворачивает свёрнутую родительскую задачу |
| <kbd>ArrowLeft</kbd> | `arrowleft` | Сворачивает развёрнутую родительскую задачу. Если задача уже свёрнута или не имеет дочерних задач, перемещает выделение к родительской задаче |
| <kbd>Tab</kbd> | `tab` | Понижает уровень вложенности задачи на один |
| <kbd>Shift</kbd>+<kbd>Tab</kbd> | `shift+tab` | Повышает уровень вложенности задачи на один|
| <kbd>Ctrl(Cmd)</kbd>+<kbd>D</kbd> | `ctrl+d` | Дублирует выбранную задачу на том же уровне |
| <kbd>Ctrl(Cmd)</kbd>+<kbd>C</kbd> | `ctrl+c` | Копирует выбранную задачу в буфер обмена, включая все дочерние задачи |
| <kbd>Ctrl(Cmd)</kbd>+<kbd>V</kbd> | `ctrl+v` | Вставляет скопированную задачу на тот же уровень, что и текущая выбранная задача. Скопированную задачу можно вставить на любой уровень, структура скопированной задачи сохраняется |
| <kbd>Ctrl(Cmd)</kbd>+<kbd>Z</kbd> | `ctrl+z` | Отменяет последнее действие (undo) |
| <kbd>Ctrl(Cmd)</kbd>+<kbd>Y</kbd> /<br><kbd>Ctrl(Cmd)</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | `ctrl+y` /<br>`ctrl+shift+z` | Повторяет отменённое действие (redo) |
| <kbd>Alt</kbd>+<kbd>1</kbd> /<br><kbd>Alt</kbd>+<kbd>2</kbd> /<br><kbd>Alt</kbd>+<kbd>3</kbd> | `alt+1` /<br>`alt+2` /<br>`alt+3` | Устанавливает приоритет выбранной задачи (соответствует горячей клавише элемента [`priorities`](api/configs/priorities_config.md)) |
| <kbd>Alt</kbd>+<kbd>0</kbd> | `alt+0` | Сбрасывает приоритет выбранной задачи |

### Режим редактирования {#editing-mode}

Следующие сочетания клавиш работают, когда встроенный редактор **открыт**.

| Горячая клавиша | Код клавиши | Описание |
| :-------------- | ----------- | :------- |
| <kbd>Escape</kbd> | `escape` | Закрывает редактор без сохранения изменений |
| <kbd>Enter</kbd> | `enter` | Закрывает редактор и сохраняет изменения |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | `shift+enter` | Создаёт новый абзац |
