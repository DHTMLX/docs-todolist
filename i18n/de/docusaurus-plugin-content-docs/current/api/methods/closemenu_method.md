# closeMenu()

### Beschreibung {#description}

@short: Schließt das geöffnete Menü einer Aufgabe/eines Projekts

### Verwendung {#usage}

~~~js
closeMenu({
    id?: string | number
}): void;
~~~

### Parameter {#parameters}

- `id` - (optional) die ID der Aufgabe/des Projekts, deren Menü geschlossen werden soll. Wenn nicht angegeben, schließt die Methode das aktuell geöffnete Menü
