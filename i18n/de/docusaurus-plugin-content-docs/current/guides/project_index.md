# Projekte verwalten

:::info
Um Projekte zu konfigurieren, verwenden Sie die Eigenschaft [`projects`](api/configs/projects_config.md) der To Do List.

Um eine Aufgabe einem Projekt zuzuweisen, übergeben Sie die Projekt-ID an den Parameter `project` des zugehörigen [`task`](api/configs/tasks_config.md)-Objekts.

Um bei der Initialisierung ein Projekt als aktiv festzulegen, verwenden Sie die Eigenschaft [`activeProject`](api/configs/activeproject_config.md).
:::
